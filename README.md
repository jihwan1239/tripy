# 삿포로 여행 일정

친구들과 같이 보는 여행 일정 웹앱. 지도, 일정표, 준비사항 3개 탭으로 되어 있습니다.

## 파일 구성

```
index.html      화면 전체 (수정할 일 없음)
config.js       관리자 설정 파일 (여기만 수정)
manifest.json   홈 화면 앱 설치용 설정
sw.js           오프라인 캐시
icon-192.png    앱 아이콘
icon-512.png    앱 아이콘
ai-proxy/       AI 프록시 서버 코드 (GitHub에 올릴 필요 없음)
```

## 1. GitHub Pages에 올리기

1. 저장소를 만들고 위 파일들을 **루트에** 올립니다.
2. Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 지정합니다.
3. 몇 분 뒤 `https://<계정명>.github.io/<저장소명>/` 으로 접속됩니다.

## 2. 친구들이 앱처럼 쓰기

배포 주소를 휴대폰 브라우저로 연 뒤 홈 화면에 추가하면 앱 아이콘이 생기고,
주소창 없이 전체화면으로 실행됩니다.

- **아이폰(Safari)**: 공유 버튼 → 홈 화면에 추가
- **안드로이드(Chrome)**: 우측 상단 메뉴 → 앱 설치 (또는 홈 화면에 추가)

## 3. 여행방 (그룹별 분리)

주소의 `?trip=` 값이 **여행방**을 결정합니다. 방마다 일정·숙소·항공편이 완전히 분리돼요.

- 앱 공유 창에서 **새 여행 만들기**를 누르면 임의의 방 ID가 만들어지고 그 주소로 이동합니다.
- 그 주소를 받은 사람만 같은 일정을 함께 봅니다. 지인 A 일행과 지인 B 일행이 서로 섞이지 않아요.
- 방 ID는 14자리 임의 문자열이라 추측으로 들어올 가능성은 사실상 없습니다.
- 다만 **링크를 아는 사람은 누구나 수정 가능**합니다. 완전한 접근 제어가 필요하면
  Supabase 인증(로그인)을 붙여야 합니다.

## 4. 처음 시작할 때 (온보딩)

새 여행방을 처음 열면 여행 이름과 **나라**를 묻는 화면이 나옵니다. 고른 나라에 따라

- 지도·장소 검색의 기준 좌표
- 공휴일 조회 국가
- AI 추천 프롬프트의 도시·통화
- **대중교통 안내 방식**

이 자동으로 맞춰집니다. 여행지는 나중에 `여행 설정 → 여행지`에서 바꿀 수 있습니다.

### 대중교통 안내 방식

| 나라 | 방식 |
|---|---|
| 일본 | 구글이 대중교통을 지원하지 않아 **AI 추천 3가지**(최소 시간 / 최소 환승 / 최소 도보) 중 선택 |
| 그 외 | **구글 경로**를 그대로 사용 (노선명·시각표·요금) |

## 5. 친구들과 일정 함께 편집하기 (동기화)

기본 상태에서는 각자 자기 기기에만 저장됩니다. 한 사람이 일정을 고쳐도 친구 화면에는 반영되지 않습니다.
(공유 버튼으로 나오는 링크는 **그 순간의 일정을 복사해서 전달**하는 방식입니다)

같은 일정을 함께 보고 고치려면 무료 데이터베이스인 Supabase를 연결하면 됩니다.

1. [supabase.com](https://supabase.com)에서 무료 계정을 만들고 프로젝트를 생성합니다.
2. 좌측 메뉴 **SQL Editor**에서 아래를 실행합니다.

```sql
create table trips (
  id text primary key,
  data jsonb,
  updated_at timestamptz default now()
);

alter table trips enable row level security;

-- 링크를 아는 사람이 읽고 쓸 수 있게 허용
create policy "anyone can read"  on trips for select using (true);
create policy "anyone can write" on trips for insert with check (true);
create policy "anyone can update" on trips for update using (true);
```

3. Settings → API에서 **Project URL**과 **anon public** 키를 복사합니다.
4. `config.js`에 붙여넣습니다.

```js
SUPABASE_URL: "https://xxxxxxxx.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGci...",
TRIP_ID: "sapporo-2026"
```

이제 접속한 사람 모두가 같은 일정을 보고, 누가 수정하면 약 15초 안에
다른 사람 화면에도 반영됩니다. 화면 상단의 점이 초록색이면 동기화 중입니다.

> 위 정책은 **주소를 아는 사람은 누구나 수정 가능**한 설정입니다. 친구들끼리 쓰기엔 충분하지만,
> 완전히 비공개로 하려면 Supabase 인증을 붙여야 합니다.
> `TRIP_ID`는 여행방 이름이라 추측하기 어려운 값으로 바꿔두면 조금 더 안전합니다.

## 4. AI 추천 켜기

OpenAI 키를 `config.js`에 직접 넣으면 **사이트 주소로 누구나 그 키를 열어볼 수 있습니다.**
저장소를 비공개로 만들어도 소용없습니다. 배포된 파일은 공개되기 때문입니다.

그래서 키를 보관하는 작은 서버(프록시)를 하나 두고, 웹앱은 그 주소만 호출하게 했습니다.
무료로 됩니다. 아래 둘 중 편한 쪽을 고르세요.

### 방법 A. Cloudflare Workers (추천, 5분)

1. [dash.cloudflare.com](https://dash.cloudflare.com) 가입 → **Workers & Pages** → **Create** → **Worker**
2. 이름을 정하고(예: `sapporo-ai`) 배포한 뒤 **Edit code**를 누릅니다.
3. `ai-proxy/cloudflare-worker.js` 내용을 전부 붙여넣습니다.
   맨 위 `ALLOWED_ORIGINS`를 본인 주소(`https://내계정.github.io`)로 바꾸세요.
4. **Settings → Variables and Secrets → Add** 에서
   이름 `OPENAI_API_KEY`, 타입 **Secret**, 값에 실제 키를 넣고 저장합니다.
5. 배포 후 나온 주소(`https://sapporo-ai.내계정.workers.dev`)를 `config.js`에 적습니다.

```js
AI_PROXY_URL: "https://sapporo-ai.내계정.workers.dev",
```

### 방법 B. Supabase Edge Function

일정 동기화로 이미 Supabase를 쓰고 있다면 이 쪽이 편합니다.

1. Supabase 대시보드 → **Edge Functions** → 새 함수 생성 (이름: `ai-recommend`)
2. `ai-proxy/supabase-edge-function.ts` 내용을 붙여넣고 `ALLOWED_ORIGINS`를 수정 후 배포
3. **Edge Functions → Secrets**에 `OPENAI_API_KEY` 추가
4. `config.js`에 주소를 적습니다.

```js
AI_PROXY_URL: "https://<프로젝트>.supabase.co/functions/v1/ai-recommend",
```

### 프록시 없이 쓰기 (임시)

`AI_PROXY_URL`을 비워두면, AI 추천 버튼을 눌렀을 때 **각자 자기 OpenAI 키를 입력**하는 화면이 나옵니다.
입력한 키는 그 사람 기기에만 저장되고 다른 사람에게 전달되지 않습니다.
관리자 혼자 테스트할 때 쓰기 좋지만, 친구들에게 각자 키를 발급받으라고 해야 해서 실사용에는 불편합니다.
아예 막고 싶으면 `ALLOW_PERSONAL_AI_KEY: false`로 두세요.

### 비용 관리

프록시를 쓰더라도 **주소를 아는 사람은 호출할 수 있습니다.** 친구들끼리 쓰는 수준이면 문제없지만,
안전하게 하려면 OpenAI 대시보드에서 **월 사용 한도(usage limit)**를 낮게 걸어두세요.
프록시 코드에는 이미 허용 주소 제한, 일정 개수 상한, 응답 토큰 상한이 들어가 있습니다.

## 5. 지도 API 설정 (선택)

`config.js`의 값을 비워두면 해당 기능은 자동으로 꺼지고,
화면에 `API 비활성화 상태입니다.`라고 표시됩니다.

| 설정값 | 비워둘 때 | 채울 때 |
|---|---|---|
| `GOOGLE_MAPS_API_KEY` | 기본 지도(OpenStreetMap) | 구글 지도 |
| `ENABLE_DIRECTIONS` | 구간 소요시간을 거리 기반 추정치로 표시 | 구글 경로 기준 실제 소요시간 |

`ENABLE_DIRECTIONS`는 `GOOGLE_MAPS_API_KEY`가 있어야 하고,
Google Cloud Console에서 **Directions API**도 함께 활성화해야 합니다.

구글 지도 키는 Cloud Console에서 **HTTP 리퍼러 제한**을 걸고
`https://<계정명>.github.io/*` 만 허용하세요. 사용량 상한도 함께 걸어두는 걸 권합니다.

Supabase anon 키는 공개를 전제로 만들어진 키라 노출 자체는 문제되지 않습니다.
대신 앞에서 설정한 RLS 정책이 실제 접근 범위를 결정하니 정책을 신경써서 설정하세요.

현재 연동 상태는 지도 화면 우측 상단의 ⓘ 버튼에서 확인할 수 있습니다.

## 6. 사용 메모

- **숙소**: 일정표 탭 상단의 숙소 줄을 눌러 **그 날 밤에 묵는 곳**을 지정합니다.
  지정한 숙소는 **다음 날 일정의 첫 출발지**로 자동으로 들어갑니다.
  (첫날은 공항 도착일이라 숙소 출발이 생기지 않습니다)
  - 숙소를 따로 지정하지 않은 날은 **이전 날 설정을 그대로 이어받습니다.**
    같은 숙소에 계속 묵으면 한 번만 지정하면 되고, 중간에 옮기면 그 날에만 새로 지정하면
    이후 날짜에 자동으로 이어집니다. 이어받은 날은 `이어받음` 표시가 붙습니다.
  - 자동으로 들어간 항목에는 `숙소 출발` 배지가 붙고, 시간은 그날 첫 일정 30분 전으로 잡힙니다.
  - 필요 없는 날은 그 항목을 삭제하면 되고, 삭제한 날에는 다시 추가되지 않습니다.
- **안(案) 나누기**: 날짜 아래 칩으로 하루에 여러 계획을 만들 수 있습니다.
  `+`로 안을 추가할 때 지금 일정을 복사할지 빈 안으로 시작할지 고를 수 있고,
  안끼리는 일정·이동수단이 서로 영향을 주지 않습니다.
  **선택된 안 칩을 한 번 더 누르면 이름을 바꿀 수 있습니다** (예: `오타루 코스`, `비 오는 날`).
  직접 지은 이름은 다른 안을 지워도 자동 번호로 되돌아가지 않습니다.
- **날짜 추가/편집**: 일정표 탭 상단의 `+ 날짜` / `날짜 편집` 버튼
- **장소 추가**: 일정표 탭 하단의 `+ 이 날 일정에 장소 추가`.
  위치 검색창에 두 글자 이상 입력하면 구글 지도처럼 후보가 실시간으로 뜨고,
  고르면 좌표와 주소가 자동으로 채워집니다. 이름 칸이 비어 있으면 장소 이름도 같이 들어갑니다.
  구글 키가 없으면 OpenStreetMap → Photon 순으로 검색하는데 정확도가 많이 떨어지니,
  그때는 `지도에서 직접 찍기`로 지정하는 편이 빠릅니다.
  구글 자동완성을 쓰려면 Cloud Console에서 **Places API**도 사용 설정해야 합니다.
- **이동수단**: 일정 사이의 칩(도보 / 대중교통 / 택시 / 렌터카)을 누르면 선택됩니다.
  지도에는 **도보만 실제 보행로를 따라** 회색 점선으로 그려지고,
  대중교통·택시·렌터카는 **수단 색의 직선 점선**으로 단순하게 표시됩니다.
  (실제 노선 선형을 그리면 지도가 복잡해져서 의도적으로 단순화했습니다)
  범례는 그날 실제로 쓰인 수단만 나타납니다.
- **대중교통 안내의 한계**: 구글 Directions API는 **일본 대중교통을 지원하지 않습니다.**
  (자동차·도보는 정상 동작하지만 transit 모드는 일본에서만 제외되어 ZERO_RESULTS가 돌아옵니다.)
  그래서 대중교통 구간의 일정표 탭에는 두 가지 대안을 제공합니다.
  - `구글 지도에서 보기` — 구글 지도 앱으로 넘어가 실제 노선·시각표·요금 확인
  - `AI로 경로 추정` — AI가 노선과 예상 요금을 제안 (지도에는 그리지 않음)
- **여행 중 편의**: 여행 기간에 앱을 열면 오늘 날짜가 자동으로 선택되고,
  날짜 칩에 `오늘` 표시가 붙습니다. 지금 시각에 해당하는 일정은 붉게 강조됩니다.
- **AI 추천**: 두 가지 버튼이 있습니다. `이 날 전체 추천`은 하루 동선 전체를 보고 어울리는 곳을 찾고,
  `다음 코스 추천`은 지도 탭에서 선택한 장소 바로 다음에 들를 만한 곳을 찾아줍니다.
  두 번째 버튼은 장소를 선택한 상태에서만 활성화됩니다.
- **준비사항 체크**: 각자 기기에만 저장됩니다. 친구 화면과 공유되지 않습니다.
- 파일을 수정했는데 반영이 안 되면 `sw.js`의 `CACHE` 버전 숫자를 올려주세요.
